What are we actually doing? ▼
  1. You upload a FASTA file — DNA sequences from environmental samples (e.g. seawater eDNA).
  2. K-mer encoding — Each sequence is turned into a vector of short sub-sequence (k-mer) counts, so we can compare sequences without a reference genome.
  3. UMAP — We reduce that high-dimensional vector to 2D so we can visualize and cluster it.
  4. HDBSCAN — We find groups (clusters) of similar sequences; points that don’t fit any group are labeled as “noise” (−1).
  5. Biodiversity metrics — From cluster sizes we compute richness (number of clusters), Shannon diversity, and Simpson diversity.
  6. Novelty & taxonomy — We score how “novel” each sequence/cluster is (distance from cluster center). If BLAST is set up, we optionally annotate clusters with the best match from a reference database.

So in short: upload FASTA → k-mers → UMAP → cluster (HDBSCAN) → biodiversity + 2D plot + optional taxonomy.
